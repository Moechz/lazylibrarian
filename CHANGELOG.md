# Changelog

All notable user-visible changes to the LazyLibrarian TOS application package.

## 2026.11.07-1 — 2026-11-08

### Added
- First release. LazyLibrarian (`linuxserver/lazylibrarian:8b6ba443-ls392`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8008 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/lazylibrariandocker/`.
